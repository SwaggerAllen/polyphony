01 · The screen you get when there isn't one

Self-contained, and still ours

This page inlines everything, because a broken asset can be the error being shown. That constraint decides the implementation and not the look: the values below are the kit's own, written out literally rather than referenced. Today's page invents its own palette and a system font stack, and reads as a different product.

The copy changes too. Today every status says Something went wrong — including the 404, where nothing did.

02 · The other four

A 403 is the one state allowed to know whether you're signed in, because it cannot be reached without auth having already run — deciding something is forbidden means knowing who asked. Everything else on this page renders without a session, since a session is exactly what may be broken.
