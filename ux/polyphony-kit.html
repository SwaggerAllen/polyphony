Polyphony · the kit

Every part, once

Everything in polyphony-kit.css, drawn. Each screen file links that stylesheet and defines nothing of its own, so a change here reaches all ten. If you find yourself writing a new class while porting, it belongs in the kit rather than in a screen.

02 · Status colour

Four semantics, and eight voices

lamp — now

The live turn, the current beat, generating, an unsaved draft. The only bright thing on screen, so attention has one meaning everywhere.

pencil — correction

Reroll, edit, delete, branch, whisper markers, every error. Never a primary action.

ok — done

Saved, published, accepted into canon. Used sparingly; most success is silent.

secret — concealed

A fact, canon entry or arc item not everyone knows. Also the audience picker and preview-as banners.

03 · Type

Three faces, and no italics

Spectral — .ttl

Names things: screen titles, campaign and scene names, character labels, and Director narration — the one place it does body work.

Archivo — default

Everything else, including all prose in a transcript. Chosen partly for legibility: purpose-built dyslexia faces test no better than a plain sans.

IBM Plex Mono — .mono / .lbl

Beats, ids, money, and the small uppercase labels.

No italic carries meaning

Four move types used to be told apart by slant. Italics measurably impair reading for dyslexic readers, and slant is a weak signal at small sizes anyway. Each now has a structural device:

Thoughtvoice-coloured rule and tint
World eventrules above and below, hanging dash, Spectral
Demeanorgutter label, one step down in contrast
Whispera coloured marker line under the speech

Italic inside an author's own prose is theirs and stays. This rule is about the interface.

05 · The perspective control

The most important idiom in the product

Identical markup and identical position — top right of the header — on every surface with a viewpoint. It drifted into three treatments during design and that was the single worst consistency failure of the whole pass, so it lives here and nowhere else.

Every variant
Omniscient ▾ Everyone shared ▾ Spectator ▾ Wren ▾ Ilias ▾

Set --vc to the character's voice colour. --bc for omniscient, --lamp for limited omniscient, --bcm for spectator.

Limited omniscient takes the reading register, not the author's — it's a way of reading, not an authoring surface.

The standard header
The Salt Line
The quay
Ilias ▾⋯

Campaign name small, scene location as the title, perspective control top right, overflow last. Play and the published reading screen use this markup unchanged — only the bottom bar differs.
